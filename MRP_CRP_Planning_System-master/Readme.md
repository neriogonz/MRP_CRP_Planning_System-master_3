## Инструкция по запуску приложения для разработки (приложение запущено локально, а база данных в контейнере):

1. Запустить контейнер базы данных командой `docker compose up postgres -d --build` ( можно без флага --build, он нужен для пресборки контейнера из образа, а у нас тут образ не меняется, нам не нужно пересобирать контейнер для базы данных)

2. Запустить приложение командой `dotnet run`

3. Перейти по адресу в браузере, где развернут проект ( по умолчанию http://localhost:5084)


## Инструкция по запуску приложения для разработки (приложение и база данных запущены в контейнере):

1. Запустить группу контейнеров командой `docker compose up -d --build`

2. Перейти по адресу в браузере, где развернут проект ( по умолчанию http://localhost:8080)


## Как работать с миграциями базы данных

Для создания миграции необходимо запустить команду  `dotnet ef migrations add Имя миграции `

Для применения созданных миграций к базе данных нужно запустить команду `dotnet ef database update` (база данных при этом должна быть запущена, и настройки контейнера базы и настройки в файле ___appsettings.json___ ( в частности строка подключения к базе данных) ). При этом dotnet ef должен быть установлен, если это не так, то нужно вписать команду `dotnet new tool-manifest` для локальной конфигурации окружения, а затем `dotnet tool install dotnet-ef`
